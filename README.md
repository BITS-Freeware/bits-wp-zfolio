# zFolio for WordPress

A WordPress plugin by [Bristlecone IT Services](https://bristleconeit.com) that brings zFolio to WordPress sites.

The plugin is in early development. There is no release yet.

## Requirements

To be set with the first release. The other Bristlecone plugins target WordPress 6.4+ and PHP 8.3+.

## Development

This directory is the plugin root. Changes land on `main` by pull request only, and every pull request is squash-merged. Dependabot keeps GitHub Actions (and, once code lands, Composer) dependencies current.

Files used only for development (`.github/`, tests, tooling) are kept out of the release zip by `.distignore` and `.gitattributes`.

## Security

Please report a vulnerability privately through [GitHub's private vulnerability reporting](https://github.com/BITS-Freeware/bits-wp-zfolio/security/advisories/new), not in a public issue. See [SECURITY.md](SECURITY.md).

# Security Policy

## Reporting a Vulnerability

Report a vulnerability through [GitHub's private vulnerability reporting](https://github.com/BITS-Freeware/bits-wp-zfolio/security/advisories/new). Please don't open a public issue, pull request, or discussion for a security problem.

Include the plugin version, the WordPress and PHP versions, and the steps to reproduce. You will get an answer on the advisory.

## Supported Versions

Only the latest release receives security fixes.
